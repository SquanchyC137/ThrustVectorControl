# Agent Rules for Thrust Vector Control Project

Diese Datei definiert Verhaltensregeln für den KI-Agenten in diesem Projekt.

## Generelle Arbeitsweise
- **Pair Programming**: Der User möchte den Code verstehen und selbst implementieren.
- **Erklären vor Lösen**: Gib nicht nur die fertige Lösung, sondern erkläre den Ansatz und die Architektur.
- **Iterativ**: Zerlege große Aufgaben in kleine Schritte.
- **Review**: Biete Code-Reviews an und weise auf potenzielle Fehler oder Randfälle hin.
- **Skeletons**: Erstelle Gerüste (bspw. leere Klassen/Methoden), die der User selbst ausfüllen kann.

## Technische Vorgaben
- **Sprache**: C++ (für ESP32/PlatformIO) & HTML/JS (für Webinterface).
- **Stil**: Halte dich an den bestehenden Code-Stil (z.B. Klassen-Struktur in `main.cpp`).
- **Kommentare**: Kommentiere Code auf Deutsch oder Englisch (konsistent halten).

## Kommunikation
- **Sprache**: Deutsch (wie in der Konversation begonnen).
